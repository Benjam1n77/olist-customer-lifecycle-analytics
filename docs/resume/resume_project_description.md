# Olist 电商客户生命周期与精细化运营分析

- **项目背景：** 基于 Olist 巴西电商公开数据，围绕复购、留存、客户价值与配送体验开展多表交易分析。
- **数据建模：** 使用 MySQL 完成一对多业务表预聚合，构建订单宽表 `mart_order_summary` 与用户宽表 `mart_customer_features`，避免 JOIN 造成金额和数量重复计算。
- **用户分析：** 以 `customer_unique_id` 为主体构建 RFM、生命周期与履约标签；成熟首购客户 90 天跨日二购率 1.2969%，多商品首单与二购呈正向关联（OR=1.4099）。
- **核心发现：** 识别 10,915 名高价值流失用户，其历史支付金额占比 30.89%；首单低评分与 90 天二购呈负向关联（OR=0.7371），延迟订单评分较准时订单下降 40.24%。
- **运营应用：** 输出高价值维护、流失召回、首购二购激励和履约关怀人群，并生成 Tableau 数据与 A/B 测试方案；尚未开展真实触达或实验。
